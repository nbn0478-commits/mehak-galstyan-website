# Инструкция по добавлению фото Мехака Галстяна

## Шаги:
1. Сохрани изображение Мехака Галстяна как `mehak-galstyan.jpg` в папку `images/`
2. Размер должен быть примерно 1400x1000px для лучшего качества
3. Формат: JPG с качеством 80-90%

## Путь к файлу:
```
м1/images/mehak-galstyan.jpg
```

Сайт уже настроен на использование этого изображения!
